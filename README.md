# Order Checkout Page (RTL)

A clean, modern, and fully responsive **E-Commerce Order Checkout Page** designed with a Right-to-Left (RTL) layout, built using semantic HTML5 and modern CSS3.

## 🔗 Live Demo
[View Live Project](https://mohsen-ak404.github.io/order-checkout-page/)

## ✨ Features
- **RTL Layout & Persian Typography:** Styled with the custom **Vazirmatn** font for clear and readable Persian UI.
- **Responsive Design:** Built using a `rem`-based scaling system (`62.5%` root font size) and CSS Grid/Flexbox to adapt seamlessly across desktop, tablet, and mobile screens.
- **Recipient & Delivery Form:** Includes structured inputs for personal details, custom-styled `<select>` dropdowns for province/city, and postal address fields.
- **Interactive Shipping Method Cards:** Custom radio-button cards with active selection states (`:has(input:checked)`) for choosing shipping options.
- **Order Summary & Invoice:** Displays cart items with quantity controls, itemized pricing, shipping costs, total payable amount, and payment gateway notice.

## 🛠️ Technologies Used
- **HTML5** (Semantic markup)
- **CSS3** (CSS Variables, CSS Grid, Flexbox, Media Queries)
- **Vazirmatn Font**
